# Web app

`web/` is a browser version of Xray Forge, published to GitHub Pages by `.github/workflows/pages.yml`
(Settings, Pages, Source: GitHub Actions). It has no server, no database and no network calls of its
own; the only request it can make is fetching a subscription URL you ask for.

## Layout

```
web/
  index.html, manifest.webmanifest, sw.js   PWA shell (strict CSP, offline precache)
  styles/app.css                            design tokens, light and dark
  src/engine/                               JS port of the config engine (no dependencies)
  src/ui/                                   app shell, views, helpers (no innerHTML)
  scripts/build.mjs                         copies to dist/ and stamps the service worker
  test/                                     node --test
tools/gen_web_unicode.py                    generates Python-exact whitespace/digit tables
```

## Keeping it in step with Python

The ported areas are `config.*` (parse, render, convert, export, dedup, override checks) and `mitm.*`.
`web/test/engine.test.mjs` holds expected outputs taken from the Python engine; when you change
behaviour in `xray_forge/core/`, change the matching code in `web/src/engine/` and those expectations.

Python 3.13 semantics are copied on purpose: `urlsplit`, `parse_qsl`, `quote`, strict base64,
`ipaddress`, `json.loads` error text, `str.format`, `int()` with Unicode digits and PyYAML's emitter.
`src/engine/unicode-tables.mjs` is generated by `tools/gen_web_unicode.py`, and
`tests/test_web_unicode.py` fails when it goes stale.

## Known differences from the desktop app

- No health checks, scanners, WARP, MASQUE, Psiphon or core management (needs processes and sockets).
- No personal CA generation (needs OpenSSL); the MITM screen shows the OpenSSL command instead.
- Subscriptions: plain and base64 lists only. Clash YAML and sing-box JSON subscriptions are detected
  and reported as desktop-only. URL fetching works only for servers that send CORS headers; others
  can be pasted.
- Settings and the working list live in this browser's local storage, not in `~/.xray_forge`.

## Design notes

Slate surfaces with one iris accent; ember is used only for warnings. A left rail on desktop, a bottom
bar on phones, the editor as a side inspector or a full-screen sheet, native dialogs, toasts, no page
scroll, safe-area insets, 44px-class touch targets, reduced-motion support.
